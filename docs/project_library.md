# 澄川建设多项目演示

澄川建设是一家虚构的建筑公司。总部资料岗需要在住宅交付、市政竣工资料和机电运维接管三个项目间切换。每个项目有四份业务制度、一份协调会纪要和一份两页的 PDF 回执。样本中的岗位、日期和时限均为项目内部的演示设定。

| 工作台项目 | 业务线索 | 原件举例 |
| --- | --- | --- |
| XR03 星榕安置房二期 | 三号楼资料交付物业，跟进门牌对照表缺件 | 分户查验问题单闭环办法、物业接管资料包编目清单、三号楼物业资料交接回执 |
| BH04 滨河路综合改造 | 西段竣工测量成果交接，核对电子成果目录页 | 竣工测量成果交付清单、设计变更资料归并规则、西段测量成果接收回执 |
| SG05 松港产业园机电工程 | 冷站接管，核对设备手册与维护点位索引 | 设备随箱资料登记细则、联调记录组卷要求、冷站运维资料签收单 |

## 初始化台账并登录

在 SecureAgent 根目录的 Windows CMD 执行下列命令。第一条导入可重跑，第二条仅在首次创建总部演示账号时执行。按终端提示在本机设置口令。

```bat
.\.venv\Scripts\python.exe -m app.demo_projects
.\.venv\Scripts\python.exe -m app.workbench_accounts add portfolio-employee --role employee --project XR03 --project BH04 --project SG05
```

这条命令授予本次导入的三个项目的员工权限。如果台账中还登记了 QL01、HT02，可在首次建号时按实际需要追加这两个项目。仅属于单个项目的员工账号适合演示项目隔离。

首次导入登记 20 个版本，包含 18 份现行文档、XR03 的一份待审批修订和 BH04 的一份历史版。初始化直接登记这份虚构的期初台账，操作记录中的导入人为 `demo-library-import`。日常上传和后续换版继续由资料员、审批人操作。原件与初始状态清单位于 `examples/project_library/`。重复导入会按版本标识和原件摘要核对，现场已经批准的新修订会保留其当前状态。

要让这三个新项目自动进行问答，在已有密钥和本地嵌入模型的服务端 CMD 中启动服务。该例为本次导入的三个项目启用问答。

```bat
set "SECUREAGENT_RETRIEVAL=hybrid"
set "SECUREAGENT_ALLOW_REMOTE_QA=1"
set "SECUREAGENT_QA_PROJECTS=XR03,BH04,SG05"
.\.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

刷新工作台，以 `portfolio-employee` 登录，在“当前项目”选择带中文名称的项目。使用本地检索的项目会列出现行原文和出处。[本机工作台](http://127.0.0.1:8000/workbench)

## 在三个项目问同一句话

> 接收方签收移交清单后，谁要在几个工作日内归档？

| 项目 | 初始现行答案 | 引用 |
| --- | --- | --- |
| XR03 | 住宅项目资料员，2 个工作日 | XR-DC-101 · R01 · §2.1 |
| BH04 | 道路项目文控员，3 个工作日 | BH-DC-101 · R02 · §2.1 |
| SG05 | 机电资料员，1 个工作日 | SG-DC-101 · R01 · §2.1 |

## 沿着批次号查原件

在 BH04 问“BH-CG-042 回执登记的待补附件是什么，由谁补交？”。西段电子成果目录页由测量资料员补交。点开 BH-RC-307 R01 §2.1，打开归档原件时应定位到第 2 页；第 1 页有逐件清点表。XR03 的批次 XR-JJ-061 缺公共区门牌对照表，SG05 的批次 SG-YW-033 缺冷站维护点位索引，详情也在对应回执第 2 页。

另一个缺少依据的问题是“这批资料延迟归档的罚款金额是多少？”。这些样本提供归档时限与补件流程，未规定罚款金额。

## 由审批人推动答案更新

需要演示换版时，用下列命令首次创建仅有 XR03 权限的演示审批人，再通过浏览器完成审批。

```bat
.\.venv\Scripts\python.exe -m app.workbench_accounts add portfolio-reviewer --role reviewer --project XR03
```

1. 用员工账号在 XR03 问上面的归档问题，核对初始答案为 2 个工作日。
2. 用 `portfolio-reviewer` 登录，预览 XR-DC-101 R02 的 §2.1。该草稿把期限改为 1 个工作日。核对后点击“批准并发布”。
3. 切回员工，重新问原问题。应引用 R02 并显示 1 个工作日。切换到 BH04 后仍应引用该项目的 R02 并显示 3 个工作日。
